雨のお告げ
[https://raw.githubusercontent.com/EngineMaker/rain-alert/main/assets/icon.png]
[* シェアハウスのまわりで雨が降り始めたら・止んだら、Discord でお知らせしてくれる仕組み]
 EngineMakerβ版 の Discord に「雨のお告げ」という名前で投稿されます

[** どんな通知が来るの？]
 降り始めたとき → [* いつごろ止みそうか] と一緒にお知らせ
  ☔ 自宅まわりで雨が降ってきました（弱い雨）。[* 22:40ごろ止む見込み]です。
  ☔ 自宅まわりで雨が降ってきました（強い雨）。[* 1時間以内には止まない見込み]です。
 止んだとき → [* 次にいつごろ降り出しそうか] と一緒にお知らせ
  🌤 自宅まわりの雨が止みました。[* 23:10ごろまた降り出す見込み]です。
  🌤 自宅まわりの雨が止みました。[* 1時間以内は降らない見込み]です。
 雨の強さは「弱い雨／やや強めの雨／強い雨／土砂降り／激しい雨」の5段階で書きます

[** こんなときに]
 出かける前に傘がいるか知りたい
 洗濯物を外に干してよいか、取り込むべきか知りたい
 「いつ止むの？」を待って出かけるタイミングを決めたい

[** 知っておいてほしいこと]
 [* 予定時刻は1時間先までしか分かりません]
  元にしている雨の予報が1時間先までしかないためです。それより先は「1時間以内には止まない見込み」のように書きます
 [* 5〜10分くらい遅れて届きます]
  5分ごとに雨の様子を確かめていて、ぱらつきで通知が連発しないよう「しばらく降り続いたら」「しばらく止んだままなら」通知しています
 [* 予報なので外れることもあります]
  特に夏の夕立のような急な雨は読み切れないことがあります
 [* 深夜も通知します]
  うるさいときは、チャンネルの通知設定（チャンネル名を長押し or 右クリック →「通知設定」）でミュートしてください

[** いまの状況]
 いまは [* #sandbox チャンネルで試運転中] です
 通知の回数やタイミングを調整して、良さそうなら専用のチャンネルを作ってそちらに移します
 「通知が多すぎる」「実際と違った」「こういう言い方がいい」などあれば、えむけーまで気軽にどうぞ

[** 仕組み（気になる人向け）]
 Yahoo! JAPAN の気象情報 API から、シェアハウスの位置の「いまの雨の強さ」と「1時間先までの予報（5分刻み）」を5分ごとに取得しています
 降り始め：1時間あたり1mm以上の雨が10分ほど続いたら
 止み：1時間あたり0.5mm未満が15分ほど続いたら
 一度お知らせしたら30分は逆向きのお知らせを出しません（ぱらつき対策）
 プログラムはえむけーのサーバーで動いています
 ソースコード：[https://github.com/EngineMaker/rain-alert]

[** きっかけ]
 えむけーが「東京アメッシュと歌舞伎町のライブカメラを並べて、外で雨が降っているかを目視で判定する体制」を作っていたところ、「降り始めたら止む時刻と一緒に、止んだら降り始める時刻と一緒に Discord に通知すれば？」と提案をもらって作りました（2026年9月）

気象情報: Web Services by Yahoo! JAPAN
