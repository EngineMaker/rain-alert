[* シェアハウスのまわりで雨が降り始めたら・止んだら、Discord でお知らせしてくれる仕組み]
 EngineMakerβ版 の Discord に「雨のお知らせ」という名前で投稿されます

[** どんな通知が来るの？]
 降り始めたとき → [* いつごろ止みそうか] と一緒にお知らせ
  ☔ 自宅まわりで雨が降ってきました（いま弱い雨）。[* 22:40ごろまで降りそう]です。
  ☔ 自宅まわりで雨が降ってきました（いま強い雨）。[* 5時ごろまでに止みそう]です。
 止んだとき → [* 次にいつごろ降り出しそうか] と一緒にお知らせ
  🌤 自宅まわりの雨が止みました。[* 23:10ごろまた降り出しそう]です。
  🌤 自宅まわりの雨が止みました。次は[* 8時ごろから降りそう]です。
  次の予報が見当たらないときは「しばらく降り続けます」「しばらく降らない見込みです」と書きます
 雨の強さは「弱い雨／やや強めの雨／強い雨／土砂降り／激しい雨」の5段階で書きます
 リビングの電光掲示板にも、雨が降っている間と30分以内に降り出しそうな間だけ表示されます
  ☔ 00:05ごろまで雨（いま弱い雨）
  ☔ 5時ごろまで雨（いま強い雨）
  🌂 22:50ごろ雨が降り出しそう
  止んでしばらく降りそうにないときは、20分ほどで表示が消えます

[** こんなときに]
 出かける前に傘がいるか知りたい
 洗濯物を外に干してよいか、取り込むべきか知りたい
 「いつ止むの？」を待って出かけるタイミングを決めたい

[** 知っておいてほしいこと]
 [* 1時間より先は「◯時ごろ」までしか分かりません]
  1時間先までは5分刻みの予報があるので「22:40ごろ」と書けますが、それより先は1時間ごとの予報（15時間先まで）しかないので「5時ごろ」と書きます
 [* 5〜10分くらい遅れて届きます]
  5分ごとに雨の様子を確かめていて、ぱらつきで通知が連発しないよう「しばらく降り続いたら」「しばらく止んだままなら」通知しています
 [* 予報なので外れることもあります]
  特に夏の夕立のような急な雨は読み切れないことがあります
 [* 深夜も通知します]
  うるさいときは、チャンネルの通知設定（チャンネル名を長押し or 右クリック →「通知設定」）でミュートしてください

[** いまの状況]
 通知は [* #em新宿_雑談_chat チャンネル] に届きます（2026-09-30 から。それまでは #sandbox で試運転していました）
 「通知が多すぎる」「実際と違った」「こういう言い方がいい」などあれば、[mktoho.icon]えむけーまで気軽にどうぞ

[** 仕組み（気になる人向け）]
 Yahoo! JAPAN の気象情報 API から、シェアハウスの位置の「いまの雨の強さ」と「1時間先までの予報（5分刻み）」を5分ごとに取得しています
 降り始め：1時間あたり1mm以上の雨が10分ほど続いたら
 止み：1時間あたり0.5mm未満が15分ほど続いたら
 一度お知らせしたら30分は逆向きのお知らせを出しません（ぱらつき対策）
 1時間より先の目安は、気象庁の降水短時間予報（15時間先まで・1時間ごと）の雨の地図から、シェアハウスの位置の色を読み取って出しています
 プログラムは105のサーバーで動いています
 ソースコード：[https://github.com/EngineMaker/rain-alert]

[** きっかけ]
 えむけーが「東京アメッシュと歌舞伎町のライブカメラを並べて、外で雨が降っているかを目視で判定する体制」を作っていたところ、「降り始めたら止む時刻と一緒に、止んだら降り始める時刻と一緒に Discord に通知すれば？」と提案をもらって作りました（2026年9月）

気象情報: Web Services by Yahoo! JAPAN、気象庁「降水短時間予報」を加工して作成
